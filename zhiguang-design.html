页面导航流程

整改后标准顺序：启动说明 → 相册权限 → 宝宝资料 → 扫描 → 结果 → 完成

PAGE 1 启动说明页
介绍 App 本地处理、不上传云端的核心理念
●首次打开：展示完整说明，点击「开始整理」进入权限页
●已授权 + 有宝宝数据：冷启动直接跳 PAGE 5 结果页
●引导中途冷启动（未走完）：从上次中断页面继续，不重走启动引导
↓
点击「开始整理」（首次）
PAGE 3 相册权限页
先申请权限再录入宝宝信息，符合 Apple 审核规范，提升授权意愿
●用户从系统设置返回 App → 强制落回本页，重新触发授权弹窗，不允许向下走流程
●后续去系统手动关闭权限 → 下次冷启动自动拦截在本页
✓ 完全授权
正常进入宝宝资料页
⚠ 部分授权
放行进入资料页，全局标记，全链路挂载黄色 Banner
✕ 拒绝权限
弹窗 +【去系统设置】按钮，返回后重落本页
⚠ 部分授权全局状态透传：权限页标记 → 扫描页底部提示 → 结果页顶部固定 Banner → 保存页提示，全程不丢失状态，不可手动关闭
↓
完全授权 / 部分授权
PAGE 2 宝宝资料页
收集宝宝信息，为人脸分组和成长节点做准备
● 昵称 必填 — 人脸分组唯一标识，空值禁止点击「下一步」
● 生日 可选 性别 可选 — 保留跳过按钮
●结果页 / 保存页提供「新增宝宝」入口，跳转本页，录入后独立触发扫描
↓
昵称已填，点击「下一步」
PAGE 4 扫描进度页
读取 → 过滤截图/二维码 → 人脸识别 → 评分 → 生成 Top 20
●部分授权状态：底部常驻小字「仅读取部分相册内容」
●中途切后台 / 杀进程：本地缓存进度，下次进入续扫，不从头重来
●相册为空：展示空页面，引导前往系统相册添加图片
↓
扫描完成
未识别到宝宝照片
弹窗二选一：
①【调整宝宝信息】→ 跳宝宝资料页，改完重新扫描
②【全量扩容扫描】→ 原地重新执行全相册扫描
禁止只做文字提示无跳转
PAGE 5 宝宝 Top 20 结果页
查看 AI 推荐结果，允许用户调整
●部分授权：顶部固定 Banner，不可手动关闭
●功能：移除 / 恢复、预览大图、保存精选
●固定入口：【新增宝宝】→ 宝宝资料页 → 独立扫描生成对应结果
●多宝宝：结果页可切换不同宝宝相册分组
●全部移除后：触发空结果页，引导重新扫描 / 新增宝宝
↓
点击「保存精选」
PAGE 6 保存完成页
确认保存成功，引导查看 / 分享
●成功：展示已保存数量，按钮：查看相册 / 系统分享 / 重新整理
●分享成功：留存本页，Toast 提示「分享完成」
●分享取消 / 失败：不跳转不刷新，Toast 提示「分享已取消 / 失败」
●固定入口：【新增宝宝】→ 宝宝资料页
↺ 「重新整理」→ 跳过权限页 & 资料页，直接进扫描进度页（权限状态已存，资料已有）
全局特殊路径
●老用户冷启动（已授权 + 有数据）：启动页 → 直接跳结果页，跳过全部引导
●部分授权全链路：权限页标记 → 扫描底部提示 → 结果页顶部固定 Banner，全程透传
●拒绝权限从设置返回：强制落回权限页，重新触发授权弹窗，不自动向下走
●新增宝宝闭环：结果页/保存页「新增宝宝」→ 资料页（昵称必填）→ 保存后独立触发扫描 → 生成该宝宝独立 Top 20
●引导中途冷启动：从上次中断页面继续（任意引导页杀进程均适用）
●后续系统关闭权限：下次冷启动自动拦截在权限页，引导重新开启

失败原因 页面表现

手机存储空间已满 提示「存储空间不足」+ 【去系统清理存储】引导按钮

项目结构

MVVM · actor Services · @MainActor ViewModels

Features/
  • Onboarding/ PAGE 1 启动说明
  • Permission/ PAGE 3 相册权限（流程第2步）
  • BabyProfile/ PAGE 2 宝宝资料（流程第3步）
  • Scanning/ PAGE 4 扫描进度
  • Results/ PAGE 5 Top 20 结果

Services/
  • PhotoLibraryService PhotoKit 封装，actor
  • ScoringEngine Vision 评分，actor

Models/
  • BabyProfile nickname(必填), birthday, gender
  • PhotoAsset / PhotoScore / ScanResult
  • PermissionState .full / .limited / .denied

→ ScanResult → ResultsViewModel → AlbumSaveService → SaveCompleteViewModel

评分算法

Vision 框架 · 规则评分 · iOS 16+ · 无需外部模型

维度权重实现方式
人脸 / 宝宝置信度 30% VNDetectFaceRectanglesRequest · 人脸大小占画面比例Vision
清晰度 25% 拉普拉斯方差（缩略图计算），严重模糊直接过滤
表情 / 眼睛状态 20% VNDetectFaceLandmarksRequest · 眼睛开合、嘴角上扬Vision
构图完整度 15% 人脸不超出画面边缘、主体居中比例
场景意义 / 连拍惩罚 10% 拍摄时间差 < 2s 视为连拍，同组最多保留 2 张，其余递减扣分
扫描范围：最近 90 天 与最近 1000 张 取并集（两个条件满足其一即纳入，上限 1000 张）
7 步流程： 读取照片 → 过滤截图/二维码/视频 → 分批50张计算清晰度 → VNDetectFaceRectanglesRequest 过滤无人脸 → VNDetectFaceLandmarksRequest 获取表情分 → 连拍分组 → 综合评分排序取前 20
