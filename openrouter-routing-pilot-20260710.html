What Terminal-Bench Means

Terminal-Bench is a benchmark built around realistic terminal-based engineering tasks. In this pilot, we used its task instruction prompts as coding-agent style workloads, so the routing test is closer to real developer-agent traffic than a generic chatbot Q&A sample.

It is also an increasingly recognized agent benchmark: public Terminal-Bench materials and leaderboards include frontier-lab usage and entries from OpenAI, Anthropic, and Google / Google DeepMind, making it a credible reference point for investor-facing technical validation.

Review Caveat

This is an early pilot, not a final routing benchmark. The sampled probes used a small output cap, and the route selected the same model for all 30 tasks. The next investor-safe version should compare explicit premium, balanced, and economy policies on full task outputs.
